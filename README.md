# Сервис инвентаризации офисных помещений

Учебный проект по дисциплине "Технологии разработки приложений на базе фреймворков".

## Назначение

Сервис помогает проводить инвентаризацию в офисе: вести учет предметов по помещениям и проверять, все ли на месте. Проверяющий обходит помещение и записывает, сколько предметов нашел и в каком они состоянии. Сервис сравнивает это с учетом и показывает результат: недостачу, излишки и предметы, которые пора заменить.

## Целевая аудитория

- сотрудники хозяйственного отдела, которые отвечают за имущество офиса;
- бухгалтерия, которой нужны итоги инвентаризации;
- ответственные за помещения.

## Предметная область

В офисе есть помещения: кабинеты, переговорные, серверная. В каждом помещении находятся предметы: мебель и техника. У предмета есть инвентарный номер, количество по учету, цена, дата покупки и срок службы. Время от времени в помещении проводят проверку: сравнивают фактическое количество предметов с учетом и смотрят их состояние. По каждому предмету записывается результат.

Правила:

- если предметов меньше, чем по учету, это недостача, ее сумма считается по цене предмета;
- если предметов больше, чем по учету, это излишек;
- если предмет неисправен или старше срока службы, его нужно заменить.

## Основные сущности

- Помещение: название, этаж, ответственный.
- Предмет: инвентарный номер, название, помещение, количество по учету, цена, дата покупки, срок службы.
- Проверка: помещение, дата, проверяющий.
- Результат: проверка, предмет, фактическое количество, состояние, итог (в наличии, недостача, излишек, требуется замена).

## Основные функции

- расчет разницы между количеством по учету и фактическим;
- расчет суммы недостачи;
- расчет возраста предмета на дату проверки;
- проверка, нужно ли заменить предмет;
- итоговый результат проверки предмета;
- учет предметов по помещениям: добавление, поиск, перемещение, списание;
- проведение проверки помещения и сохранение результатов;
- история проверок и статистика.

## План развития

На следующих этапах планируется:

- хранение помещений, предметов и проверок в файлах, меню с несколькими сценариями;
- классы для помещения, предмета, проверки и результата;
- веб-приложение на Django: страницы помещений, предметов и проверок;
- подключение базы данных;
- регистрация пользователей и роли;
- REST API для предметов и проверок;
- контейнеризация (Docker);
- настройка CI/CD.
